## Этап 0. Ревизия: что реально работает

Занимает один вечер. Нужно, чтобы дальше опираться на факты, а не на догадки.

- [ ] **Яндекс Вебмастер** — `npm run webmaster`. Покажет страницы в индексе,
      исключённые, состояние sitemap, активные проблемы из диагностики
      и поисковые запросы с показами и кликами.
- [ ] **Яндекс Метрика** — `npm run metrika`. Посещаемость, источники,
      сработавшие цели и популярные страницы.

Обе команды берут `METRIKA_OAUTH_TOKEN` из `.env.local`.
- [ ] **Тестовая заявка** с продакшена. Проверить, дошла ли на email
      и записалась ли конверсия в Метрике.

Результат: одна страница заметок с реальными цифрами — точка отсчёта.

## Этап 2. Посадочные страницы под услуги

Главная SEO-задача. Сейчас все 10 услуг живут на одной странице `/uslugi`,
поэтому сайт не может ранжироваться по конкретным коммерческим запросам
вроде «столешница из мрамора на заказ».

Семантическое ядро уже собрано — в `src/app/otchet_final.md`, раздел 2.

**Как делать технически:** динамический роут `src/app/uslugi/[slug]/page.tsx`
с `generateStaticParams()`. Тексты и SEO-поля вынести в `src/data/services.ts`,
расширив тип `ServiceItem` полями: `slug`, `seoTitle`, `seoDescription`,
`h1`, `intro`, `body`, `faq`.

**Что должно быть на каждой странице:**
- уникальные `title` и `description` под запросы из ядра;
- один `h1`, содержащий главный запрос;
- 2000+ знаков осмысленного текста (материалы, процесс, сроки, цены);
- 5–10 фотографий работ именно по этой услуге с описательными `alt`;
- блок вопросов и ответов + разметка `FAQPage`;
- хлебные крошки + разметка `BreadcrumbList`;
- форма заявки;
- перелинковка: со страницы `/uslugi` вниз на услуги, обратно наверх,
  и вбок на 2–3 смежные услуги.

**Порядок запуска.** Сначала три приоритетные услуги (в `services.ts` у них
стоит `priority: true`):

- [ ] `/uslugi/stoleshnitsy` — столешницы
- [ ] `/uslugi/lestnicy-i-stupeni` — лестницы и ступени
- [ ] `/uslugi/podokonniki` — подоконники

Затем остальные семь: камины, облицовка санузлов, фасады, барбекю,
столы и барные стойки, душевые поддоны, полы.

- [ ] После каждой партии страниц дописать URL в `src/app/sitemap.ts`
- [ ] Отправить новые адреса на переобход в Вебмастере
      («Индексирование» → «Переобход страниц»)

## Этап 3. Внешние площадки

Приносят звонки без ожидания индексации — можно делать параллельно с этапом 2.

Всё здесь делается руками в браузере, поэтому инструкция готовится так:

1. Сначала одним сообщением — все данные для ввода, готовые к вставке:
   название, адрес, телефоны, почта, график, категории, описание.
   Источники: `src/data/contacts.ts`, `src/data/services.ts`,
   семантика в `src/app/otchet_final.md`.
2. Затем шаги по одному: полный URL, название кнопки ровно как на экране,
   что ввести, как выглядит успех. Ждать подтверждения после каждого шага.
3. Результат дописать сюда: что создано, под какой почтой, ссылка на карточку,
   статус верификации.

По Яндекс Бизнесу заранее нужно решение владельца: есть ли по адресу
на Гаражной вывеска и приём клиентов. От этого зависит тип карточки —
с адресом или «выездное обслуживание».

- [ ] **Яндекс Бизнес**: создать карточку, заполнить полностью (описание, услуги,
      контакты, график, фото, логотип, территория обслуживания), пройти верификацию.
- [ ] Получить ссылку для отзывов, разослать текущим клиентам.
      Отзывы — ключевой фактор доверия в премиальном сегменте.
- [ ] **2ГИС**: карточка компании.
- [ ] **Авито**: отдельные объявления под каждую услугу, а не одно общее.

## Что зафиксировать сразу

Ключевая ставка проекта: конкуренты пишут одно и то же — «своё производство,
опыт, качество, низкие цены». У «Камня Века» есть история, поколение мастеров
и настоящее производство. На этом и надо строить тексты, а не на цене.
