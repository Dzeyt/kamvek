# Выбор модели

Тариф: Cursor Pro Plus. Cursor Models (Composer 2.5, Grok 4.5 / 4.6) включены
в подписку и расходуются из щедрого лимита. Other Models (Claude, GPT, Gemini)
тратят отдельные $70 в месяц по ценам API.
Цены проверены 2.09.2026 по https://cursor.com/docs/models — пересматривать
раз в квартал, они меняются.

## Правило

Думать — дорогой моделью, молотить — дешёвой. Планирование это пара сообщений
и центы. Выполнение это десятки вызовов инструментов, логи и диффы, и вся эта
история едет в каждый следующий запрос — поэтому дорогая модель на выполнении
стоит доллары за сессию.

| Уровень задачи | Модель | $/1M вход · выход |
|---|---|---|
| Рутина: данные в `src/data`, `alt`, мелкие багфиксы, страницы по готовому шаблону | Composer 2.5 | 0.5 · 2.5 — включено |
| Многофайловое, отладка, рефакторинг, инфраструктура | Grok 4.6 | 2 · 6 — включено |
| Архитектура, запутанные баги, тексты для клиента, ревью рискованных правок | Claude Opus 5 (thinking high) | 5 · 25 — из $70 |
| Второе мнение, когда Composer не тянет, а Grok уже пробовали | Claude Sonnet 5 | 2 · 10 |

## Переходы

- План готов и записан в файл → новый чат на Composer 2.5, выполнение по плану.
  Так дешёвая модель не тащит историю дорогой, и план не пропадает вместе с чатом.
- Дешёвая модель дважды провалилась на одном месте → поднять до Opus 5,
  а не запускать третий круг.
- Opus остался включённым на выполнении с логами и правками файлов →
  переключить вниз.

## Деньги

- Fast-режимы без нужды не включать: Composer 2.5 Fast стоит 3 · 15
  против 0.5 · 2.5 — шестикратная разница за скорость ответа.
- Auto не экономит: считается по цене той модели, куда сам сролся,
  и может уйти в платный кошелёк.
- Ориентир: планирующая сессия Opus ≈ $0.2–0.4, выполняющая ≈ $2–4.
  То есть при $70 это порядка 15–20 выполняющих сессий в месяц.
- Расход по обоим кошелькам виден в Cursor → Settings.

## Длина чатов

Один чат — одна задача. Начинать новый, когда задача сменилась, произошла
суммаризация истории или агент начал переспрашивать решённое. Платится вся
история чата в каждом запросе, поэтому длинный чат дорожает с каждым шагом.
Но не начинать новый посреди отладки: потеря контекста дороже.
